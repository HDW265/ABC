| 项目 | 内容 |
|------|------|
| **正式名称** | **Constellate（星座）跑图法** |
| 英文名 | Constellate Path |
| 状态 | **已定稿**（与当前 `js/path.js` 一致） |
| 实现 | 单线 `js/path.js`；推演表 `js/project.js` |
| 界面 | 左侧「Constellate（星座）跑图」；默认输出「单线 + 推演」 |

本文归档经手工对照确认的九方图 **Constellate（星座）跑图法** 规则，供实现对照与后续改动回归。

命名含义：路径点落在十字轴与对角「星线」上，连线如星座连点（constellate）。

---

## 1. 总规则（一句话）

**Constellate（星座）跑图法：** 从起点起交替走 **45°** 与 **180°**，每步在合法候选中取**朝目标方向最近**的一格；若该角度沿搜索方向出现**螺旋边连续价**，则**改走另一角度**，且下一拍按**实际走过的角度**接续（方案 B）；路径在**最接近目标**的结构点停止（下一步更远则不走出）。

---

## 2. 坐标系

- 方阵中心为 `(cx, cy)`，格坐标相对中心：`dr = row - cx`，`dc = col - cy`。
- 十字轴：`dr=0` 或 `dc=0`；对角：`|dr|=|dc|≠0`。
- 价格模式用格子 `value`；时间模式用 `index`。

---

## 3. 步型定义

### 3.1 45°（对角射线）

- 候选：相对当前格满足 `|Δrow| = |Δcol| ≠ 0` 的所有格。
- 过滤：价格须朝目标方向（向下则 `< 当前`，向上则 `> 当前`）。
- 选取：朝目标**最近**——向下时取候选中**最高价**（从当前往下扫到的第一击）。

示例：`594 → 560`。

### 3.2 180°（主轴对穿）

只沿**主轴**对穿，避免正轴点把整条横/竖边当成对侧：

| 当前位置 | 允许方向 |
|----------|----------|
| `|dr| ≥ |dc|`（偏南北 / 纵轴） | 仅**同列** N–S（`flip_col`） |
| `|dc| > |dr|`（偏东西） | 仅**同行** E–W（`flip_row`） |

- 候选须在中心**对侧**（异号；正轴上 `dr=0`/`dc=0` 的中线格排除）。
- 同样取朝目标最近价；同价时 `reflectGap` 较小优先。

示例：

- `560 → 523`（常规同列对穿）
- `916 → 886 → 827`（正东→正北后，180° 走竖直对穿，**不**取邻格 `885`）

---

## 4. 连续边换角（方案 B）

### 4.1 何时判定「连续」

沿**本拍计划角度**的搜索方向，从当前格逐格邻接行走：

- **180°**：沿主轴指向对侧（南←北点，东←西点，等）。
- **45°**：四条对角邻向中，朝目标方向者。

若连续至少 **`CONSEC_MIN = 2`** 步满足 `|Δ价| === step`（默认 step=1 即 `241,240,239…`），则视为螺旋边连续爬行，**不是**有效角线跳点。

### 4.2 换角

1. 计划角度连续 → 改试另一角度。
2. 另一角度不连续 → 采用另一角度（本步 `bounced=true`）。
3. 两角都连续 → 取首候选 `|Δ价|` **更大**者（跳环优先）。
4. 另一角度无候选 → 仍用原计划角度。

### 4.3 周期接续（方案 B）

下一拍角度由**本步实际使用的角度**决定：

- 实际走了 45° → 下一拍计划 180°
- 实际走了 180° → 下一拍计划 45°

因此在角点连续边上可能连续多次「计划 180 → 弹到 45」，形成对角环跳，这是预期行为。

### 4.4 典型修正

| 场景 | 旧（错误） | 定稿 |
|------|------------|------|
| `241` 上计划 180° | 同列爬边 `240…232` | 弹到 45° → `211` |
| 之后仍落在连续西边 | — | 再弹 45° → `183 → 157 → 133 → 111 → …` |

---

## 4.5 方向自动判定（UI）

由起点与目标的相对高低自动选择方向（界面 radio 只读展示）：

| 关系 | 方向 |
|------|------|
| 起点 **>** 目标 | **向下寻目标** |
| 起点 **<** 目标 | **向上** |
| `|起点 − 目标| ≤ eps`（视为相同） | **不跑图**；提示「起点与目标相同，无法判定方向，请调整高低点」，并禁用「开始跑图」 |

## 5. 到达与软落点（最接近即停）

默认 `eps = max(|step|/2, 0.5)`：

- `|当前价 - 目标| ≤ eps` → 到达；
- 否则先算出下一步候选：若 `|下一步 − 目标| ≥ |当前 − 目标|`，**不走出该步**，停在当前（路径上已最接近目标）。
- **向上 / 向下**均适用。平局（距离相等）留在当前格。

示例：

| 方向 | 路径片段 | 停点 |
|------|----------|------|
| 向上 `687→775` | `… → 768 →（802 更远，弃）` | **768**（差 7，而非 802 差 27） |
| 向下 `910→185` | `… → 183 →（再下更远，弃）` | **183**（差 2） |

若停点与输入目标差超过 `eps`，界面提示「输入目标 → 落点（差值）」（软落点）。

## 6. 回归基准链（begin=1, step=1, 向下）

改算法时至少跑通以下用例：

### 6.1 主链（不得破坏）

```text
922 → 880 → 833 → 793 → 749 → 711 → 669 → 633 → 594 → 560 → 523
```

### 6.2 正轴 180°

```text
916 → 886 → 827 → 799 → 743
```

（第二步必须是竖直 `flip_col`，禁止 `886 → 885`。）

### 6.3 连续边换角（对角爬环）

从 `910` 向下，经 `241` 后应为对角序列，例如：

```text
… → 273 → 241 → 211 → 183 → 157 → 133 → 111 → 91 → 73 → 57 → 43 → 31 → 21 → 13 → 7 → 3
```

- `#19 = 241`（45° 落到西北对角）
- `#20 = 211`（计划 180° 因连续边弹到 45°）
- 禁止：`241 → 232`

### 6.4 其它抽检

| 起点 → 目标 | 期望要点 |
|-------------|----------|
| `917 → 749` | `917 → 885 → 828 → 798 → 744` |
| `929…910 → 749` | 第二步为同列 180°，无邻格横滑 |
| `922 → 750/756` | 软落到 `749` |
| `687 → 775` 向上 | 停在 **768**，不到 802 |

## 8. 推演表（90/180 秘诀）

与单线共用几何：**表中 90° = 单线 45° 最近击**；**180° = 单线 180°**；每步均经 `resolveMoveKind`（含连续换角）。

### 8.1 分段公式

- 第 1 段：永远是起点的 **90°**
- 第 \(n\) 段（\(n\ge 2\)）全部候选 =  
  `180°(第 n−2 段全部目标) ∪ 90°(第 n−1 段全部目标)`  
  （第 2 段的「n−2」取起点）

### 8.2 定稿展示（方案 B + 先遇到）

1. 若第 \(n-1\) 段全部价 **≥3 个**：去掉 `90°(极端价)`（向下取 min，向上取 max），且该点不在 180° 组内时才去掉（例：剔除 822→804）。
2. `pickDisplay`：
   - 全在目标「未越过」侧 → 留 min+max（去中间，如 822/833/834 → 834、822）
   - 已越过侧 ≥1 → 按方向遭遇序保留前两个（例：`{805,793,792}` → **805、793**）
   - 两侧都有 → 保留未越过全部 + 越过侧先遇到的一个

### 8.3 通道明细命名

| 段数 | 模板条数 | 折叠标题 |
|------|----------|----------|
| 4 | 5 | **五通道明细** |
| 5 | 8 | **八通道明细** |
| 其他 | M | **M通道明细** |

模板填格：90° 前进 1 列；180° 空 1 列再落格。

### 8.4 回归例

```text
922 推 807 = 880 — 862、850 — 834、822 — 805、793
```

单线对照：`922 → 880 → 833 → 793`

### 8.5 UI

- 默认输出：**单线 + 推演**（可改仅单线 / 仅推演）
- 右侧：秘诀串 + **价位芯片**（点击定位）+ 通道明细折叠
- 画布：推演默认只打点；可选「通道线」
