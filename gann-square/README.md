# 江恩九方图 · Square of Nine（网页版）

纯静态网页工具：调节起始值、步长、环数，实时生成江恩九方图，支持价格/时间模式、角度高亮、价格反查、CSV/PNG 导出与链接分享。

## 需要下载到本地才能运行吗？

**不必须。** 三种用法任选：

| 方式 | 是否下载源码 | 怎么做 |
|------|--------------|--------|
| **在线打开（推荐）** | 否 | 将本目录部署到 GitHub Pages / Netlify / 任意静态托管后，用浏览器访问链接即可 |
| **本地直接打开** | 是（或打开仓库里的文件） | 双击 / 用浏览器打开 `gann-square/index.html` |
| **本地小服务器** | 是 | 在项目根目录执行下方命令，访问提示的本地地址 |

> 本工具无后端、无构建步骤、无 npm 依赖。不需要安装 Node.js。

## 本地快速预览

在仓库根目录执行：

```bash
# Python 3
python3 -m http.server 8080
```

浏览器打开：

```
http://localhost:8080/gann-square/
```

或直接打开文件：

```
gann-square/index.html
```

## 功能

- **步长 / 环数 / 起始值**：参数变更即时重绘
- **价格 / 时间** 双模式
- **十字轴 / 对角线 / 平方数** 高亮开关
- **价格反查**：输入价格定位最近格
- **选中解读**：角度、环数、同轴关联位、邻近格
- **预设模板**、**复制分享链接**、**导出 CSV / PNG**
- **缩放**与高级中心偏移（实验用）
