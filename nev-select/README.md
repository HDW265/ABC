# 新能源选号模拟（广州）

虚拟网页版交管 12123 选号沙盘，默认城市广州，支持随机选号、自编选号与管理台。

> 仅供学习演示，不产生真实号牌效力，不对接正式系统。

## 功能

- **号段公布 / 筛选**：投放日期、号段列表、7 日规则状态、**余号 X/Y**
- **新车选号流程**：基本信息 → 车辆信息 → 预选号牌
- **随机选号**：5 次「10 选 1」、不含 4、批次/备选倒计时
- **自编选号（余号池）**：仅可选尚未被占用的号码；20 次、每次最多 5 意向
- **后台消耗**：按模拟时间持续占号（优先消耗「仅随机」段），模拟他人选号
- **管理台**：号段 CRUD、时间加速、规则与消耗速率、一键爆发消耗、重置

## 验证余号池

1. 打开「号段公布」，查看各段「余号 a/b」  
2. 管理台 → 规则 →「立即消耗 50 个」或提高时间流速  
3. 余号下降后，自编已被占号码会提示「已被选取（余号池无此号）」  
4. 「恢复出厂」可重新生成带历史消耗的种子号池  

## 启动

```bash
npm install
npm run dev
```

浏览器打开终端提示的本地地址（一般为 http://localhost:5173）。

## 验证 7 日规则

1. 打开「号段公布」，查看标有「仅随机」的新投放号段  
2. 进入「管理台 → 时间」点击 **+7 天** 或提高时间流速  
3. 回到号段页 / 自编页，对应号段应变为「可自编」

## 技术栈

Vite + React + TypeScript + React Router，状态持久化在 `localStorage`。
